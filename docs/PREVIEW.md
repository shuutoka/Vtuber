# Aperçus de Vtuber Link V2

Les captures `preview-desktop.png` et `preview-mobile.png` ont été réalisées le 30 septembre 2026 avec les données présentes dans le dépôt, sans fixture ni créatrice inventée. Le précédent relevé ne contenait pas les avatars : les initiales sont donc visibles. Ils seront remplacés par les portraits publics Twitch après la première exécution du nouveau script. Les mentions LIVE de cet aperçu correspondent au relevé affiché, pas à une indication actuelle à la lecture de cette capture.

Le navigateur a vérifié huit vues à 1440, 1024, 768, 390 et 320 px, sans débordement horizontal. Les filtres et le raid ont été testés avec des données injectées uniquement dans le navigateur de test. Le formulaire, la péremption des données, l'erreur de chargement et la préférence de réduction des animations ont aussi été vérifiés.
